RUANGRPP - PANDUAN UMUM

ISI FOLDER
Simpan panduan resmi pembelajaran dan asesmen serta regulasi umum yang menjadi acuan proyek. Utamakan PDF asli.

PETUNJUK KHUSUS
Periksa tahun/versi, perubahan yang berlaku, cakupan jenjang, penerbit dan hak penggunaan. Dokumen lintas jenjang boleh disimpan utuh; jelaskan bagian yang relevan untuk SD di metadata.

ALUR TIM
1. Simpan file asli tanpa mengubah isinya; periksa duplikasi sebelum menambah salinan.
2. Gunakan nama KATEGORI_MAPEL_JENJANG_FASE-ATAU-KELAS_TOPIK_TAHUN.ext, disesuaikan cakupan nyata. Gunakan underscore.
3. Jangan menebak tahun/versi. Jika tahun tidak diketahui, gunakan Tahun_Tidak_Diketahui. Simpan nama asli di metadata.
4. Catat satu baris per file sumber di Excel pada folder 05_INVENTARIS_METADATA: ID, sumber URL, cakupan, penerbit, nama/path lokal, status, pengumpul dan tanggal.
5. Catat bukti izin dan batas penggunaannya. Publik/terunduh tidak otomatis mengizinkan layanan komersial atau unggah ulang ke GitHub.
6. Jika ragu mengenai sumber, izin atau kualitas, gunakan 99_PERLU_DITINJAU dan tulis alasannya di inventaris.
7. Teks hasil ekstraksi/OCR disimpan terpisah dari file asli saat tahap pemrosesan dimulai.

CATATAN REPOSITORI
PETUNJUK.txt menjaga folder tetap tercatat di Git meskipun belum berisi dokumen. File petunjuk ini bukan sumber RAG.
Masukkan dokumen ke repositori bersama hanya jika hak berbagi ulangnya sesuai. Jika tidak, simpan di penyimpanan tim yang berizin dan catat lokasi aksesnya.
Keberadaan file di folder tidak berarti sudah diverifikasi atau aktif untuk generator.
